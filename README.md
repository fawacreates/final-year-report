# Web Development Internship

## Introduction

This repository documents the work completed during my **4-week Web Development Internship** at **Edify Institute** as part of the **6th Semester Internship Program** under **Baldwin Women's Methodist College**.

The internship was designed to provide practical exposure to modern web development by gradually progressing from frontend fundamentals to backend integration and finally to collaborative full-stack application development. Throughout the program, I gained hands-on experience by building real-world projects, implementing industry-standard development practices, and working with modern web technologies.

Rather than focusing on a single project, the internship emphasized continuous learning through increasingly complex assignments. Each week introduced new concepts that built upon the previous week's knowledge, allowing me to understand how complete web applications are designed, developed, and deployed.

---

# Internship Objectives

The primary objectives of this internship were to:

- Strengthen the fundamentals of modern web development.
- Gain practical experience with frontend and backend technologies.
- Understand real-world software development workflows.
- Learn to integrate APIs and databases into web applications.
- Develop problem-solving and debugging skills.

## Week 4 – Capstone Project

# ExamPortal

The final week consisted of a collaborative capstone project where a team of three interns developed a full-stack online examination management system.

The application was designed to simplify examination management by providing dedicated dashboards for teachers and students while automating the examination workflow.

---

## Project Overview

ExamPortal is an Online Examination Management System that enables educational institutions to conduct digital examinations efficiently.

The application supports role-based authentication and provides separate functionalities for teachers and students.

---

## Major Features

### Teacher Module

Teachers can:

- Register and log in securely
- Create examinations
- Edit existing examinations
- Delete examinations
- Add multiple-choice questions
- Manage question banks
- Set examination duration
- View student submissions
- Publish examination results
- Access performance analytics

---

### Student Module

Students can:

- Register and log in
- View available examinations
- Attempt timed examinations
- Navigate between questions
- Submit examinations
- Receive automatic evaluation
- View examination history
- Access published results

---

### System Features

- Role-based authentication
- Responsive interface
- Dashboard analytics
- Automatic grading
- Timed examinations
- Automatic submission
- Examination management
- Performance reports
